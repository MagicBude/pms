## 验收证据要求

每个进入实现的功能至少补齐：

1. 一个真实且脱敏的旧系统案例；
2. 输入字段、输出结果和关键中间状态；
3. 正常、重复、空值、撤销/更正和权限不足场景；
4. 新旧结果差异以及差异被接受的理由；
5. 数据数量、金额或数量合计的自动对账；
6. 对应功能 ID、业务规则 ID 和自动化测试 ID。

旧数据迁移完成前，本表状态不得直接从“待设计”跳到“完成”。应依次记录设计、实现、测试、迁移演练、对账和业务验收结果。
