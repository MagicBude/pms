# 旧采购订单迁移计划

状态：设计已接受，映射实现中

## 目标

把旧 `OutsourceDatabase.xlsb` 的 1,625 行、536 张采购/外协订单转换为可重复验证的版本化规范包，
在隔离库建立完整来源链并形成逐单对账。真实值只存在于 Git 忽略区，仓库只保存规则、虚构测试和
汇总证据。

## 五段式管线

1. **原始提取**：复用 `pms-legacy-raw-v1` 的 `purchase_orders.jsonl` 和带 SHA-256 的清单。
2. **规范映射**：严格校验字段类型，以订单号分组，解析 Decimal/日期并输出
   `pms-legacy-purchase-orders-v1`；不写数据库。
3. **隔离导入**：解析主数据关系，建立迁移来源的报价、确定和已签发订单，全批事务提交。
4. **自动对账**：比较来源/目标行数、订单数、供应商边界、类型、项目/请购跨度、旧合计和重算额。
5. **业务签收**：在本地复核页确认 55 张差异订单及异常日期/备注后，才决定是否导入日常库。

## 字段口径

| 旧字段 | 规范包/新系统用途 | 处理规则 |
| --- | --- | --- |
| 订单编号 | 订单业务键 | 必填；保留原值；租户内唯一 |
| 承接方 | 供应商关系与快照 | 必须唯一匹配供应商；订单内不得混供方 |
| 项目编号、请购单号 | 明细来源链 | 允许一张订单跨项目或跨请购 |
| 件号/编码、名称 | 物料关系与快照 | 编码必填并校验名称差异 |
| 下单数量、单位 | 数量事实 | Decimal 且大于零；单位差异报告 |
| 单价 | 历史单价证据 | Decimal；税务口径标记为未知 |
| 总价 | 旧保存金额证据 | 保留原值，不覆盖重算值 |
| 数量 × 单价 | 规范重算金额 | 按人民币分四舍五入，仅用于对账 |
| 零件属性 | 订单类型 | 全采购件/全加工件/混合分别映射 |
| 备注、日期 | 历史快照 | 保留并报告异常，不擅自修正 |

## 首批自动验收

- 同一订单跨项目、跨请购时仍只形成一个订单头。
- 同一订单出现多个供应商时整包拒绝。
- 空订单号、非正数量、非法金额或未知单元格类型时整包拒绝。
- 旧总价与重算额分别保留，差异精确到分且不受浮点误差影响。
- 同一规范包重复导入不新增事实，内容漂移时回滚。
- 命令输出和异常只包含计数、批次摘要和来源行号，不泄露供应商、价格或备注。
- 跨租户不可见、不可修改；失败导入不留下半张订单或孤立报价。

## 当前边界

本计划不把未知税务口径解释为零税率，不迁移盖章文件，不自动接受 55 张差异订单，也不修改
`.internal/legacy-pms/` 或运行其中宏。业务签收前，旧系统仍是历史订单金额的原始证据来源。
