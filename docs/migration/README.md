## 迁移对象

- 客户、供应商和员工基础资料；
- 项目、订单、BOM、采购、生产和库存数据；
- 付款、发票、汇票和银行记录；
- 图纸、PDF、照片和其他附件；
- 编号规则、状态流转和报表口径；
- 旧系统中由 VBA 隐式实现的业务规则。

## 原则

- 迁移脚本可重复执行，并产生结构化结果报告。
- 原始文件只读，清洗结果写入独立暂存区。
- 每类数据都要定义字段映射、清洗规则、去重规则和校验总数。
- 迁移验收应对比记录数、金额合计、关键状态和代表性业务案例。
- 真实敏感数据不得进入 Git 或普通测试夹具。
- 工作簿存在不代表功能仍在使用；静态证据必须经过业务确认。
- 新系统允许有意改进旧行为，但差异、原因和验收结果必须可追踪。

旧系统位于 `.internal/legacy-pms/`，该路径只能作为本机参考，不能成为新系统运行依赖。
