# 旧 PMS 总迁移包

状态：总包契约已接受，各模块装配进行中

## 最终交付形式

使用者最终只需要：

```text
pms-legacy-import-bundle-v1.zip
PMS-导入全部旧数据.bat
```

BAT 将自动完成备份、完整性验证、隔离演练、重复导入检查、结构化对账和启动检查。内部 JSON 是
工程实现细节，不要求使用者逐个选择或运行。

## 使用者需要做什么

1. 在最终总包生成前，集中查看一次复核页，只回答系统确实无法从旧证据唯一判断的问题。
2. 关闭 PMS，双击导入 BAT，并保留窗口直到显示隔离演练与正式导入结果。
3. 在浏览器抽查项目、订单、库存、销售和财务代表记录。
4. 确认后按正式切换清单停止对应旧入口新增；失败时使用自动备份恢复。

不需要手工逐条录入1,625条订单，也不需要自行拼接多个命令。

## 当前限制

总包现在还不能生成“全部旧数据正式版”，因为库存、销售和财务目标模型尚未实现。采购订单总包
