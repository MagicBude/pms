# Phase 3A 第四批：物料图纸版本与订单图纸包

状态：已接受，待实现

## 1. 范围

本批完成 `PUR-004` 图纸部分：给租户物料上传版本化 PDF/DWG，在物料页面查看当前和历史图纸；
从已签发采购/外协订单生成带校验清单的版本化 ZIP，并受控下载历史包。

不实现在线 CAD 预览、DWG 转 PDF、设计审批、电子签章和旧图纸自动批量认定。

## 2. 旧行为证据

- 源码确认：旧宏拼接“件号 + 名称”并从固定目录复制 PDF/DWG，使用 `On Error Resume Next`，
  因此缺图和路径错误不会阻断或形成差异报告。
- 数据结构确认：旧 PDF 目录 405 个文件，其中 382 个名称带同步冲突标记，另有配置文本和样板
  DWG；目录存在不等于图纸已完成业务确认。
- 优化建议：以物料 ID 建立图纸事实，旧文件迁移必须先做哈希、候选匹配和人工签收。

## 3. 权限

- 管理员和 BOM 工程人员维护物料图纸；申请人员可查看并为有权管理的订单生成图纸包。
- 项目负责人按相关项目查看订单包；普通图纸库首版不向无物料图纸权限角色开放。
- 审计角色默认不读取商业订单或图纸原文。

## 4. 验收案例

| ID | Given / When / Then |
| --- | --- |
| AC-P3A-026 | 上传签名匹配的 PDF 或 DWG 后形成物料当前图纸 V1 |
| AC-P3A-027 | 同物料同格式再次上传形成 V2，V1 已替代且仍可下载 |
| AC-P3A-028 | 扩展名伪装、未知格式、空文件和超过 25 MiB 文件被拒绝 |
| AC-P3A-029 | 跨租户物料或无维护权限用户不能上传、替代或下载图纸 |
| AC-P3A-030 | 已签发订单按冻结物料选择当前 PDF/DWG，并冻结具体图纸版本 |
| AC-P3A-031 | 图纸包 ZIP 包含实际文件和 manifest，大小与 SHA-256 可逐项复核 |
| AC-P3A-032 | 部分缺图写入 manifest；全部缺图拒绝生成空包 |
| AC-P3A-033 | 同订单重复物料不会重复打包，同名文件不会静默覆盖 |
| AC-P3A-034 | 再次生成产生包 V2，旧包 V1 内容不因图纸升级而变化 |
| AC-P3A-035 | 草稿、取消订单和跨租户订单不能生成图纸包 |
| AC-P3A-036 | 上传、替代、生成和下载形成不含二进制原文的审计证据 |

## 5. 完成定义

- SQLite/PostgreSQL 迁移、事务版本、条件唯一约束和租户反向测试通过。
- ZIP 路径安全、内容签名、清单确定性、哈希和历史包不可变有自动测试。
- 使用纯虚构 PDF/DWG 在隔离数据目录完成页面和下载验收。
