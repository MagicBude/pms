# 旧系统功能清单

状态：第一轮静态提取草案

## 1. 目的与证据等级

本清单把旧 Excel/VBA 系统当作需求来源和验收基线，不要求新系统一比一复制界面或文件结构。

- **已确认**：从菜单绑定、VBA 过程、字段或查询代码直接确认。
- **待业务确认**：可以从文件名、调用关系或数据结构合理推断，但仍需使用者确认。
- **优化建议**：面向新系统的重构方向，不是旧系统事实。

第一轮选择 55 个关键工作簿进行只读静态分析；39 个含 VBA，共 317 个模块、1,309 个过程，错误 0 个。分析未运行宏，也未修改旧文件。文件存在不代表仍在实际使用。

## 2. 总菜单入口

`PMS.xlsm` 中确认到以下入口：

| 业务域 | 菜单入口 |
| --- | --- |
| 基础资料 | 项目立项、客方入档、供方入档 |

## 4. 平台性遗留能力

- `AddIns/My.xlsm` 提供大量通用数组、文件、格式、输入、消息和数据库合并函数。
- 多工作簿复制了拼音输入、下拉、窗口冻结、列格式和文件查找逻辑。
- 多个 XLSB/XLSX 文件承担“数据库”职责，工作簿通过全局路径变量读取和追加。
- `ERP系统价格查询.xlsm` 中存在硬盘序列号与 MD5 激活逻辑。

这些能力不应按工作簿逐个重写。新系统应分别沉淀为领域服务、应用服务、通用界面组件、持久化适配器、文档存储和授权模块。
