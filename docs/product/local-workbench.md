# 本机工作台操作路径

状态：已接受

## 1. 用途

Phase 2 本机工作台把 `SLICE-001` 的应用用例组合成服务端渲染页面。使用者通过
`http://127.0.0.1:8000` 操作；浏览器不会直接打开 SQLite 或附件目录，也不能提交任意
tenant、业务状态或附件存储路径。

本页只说明当前可操作范围。安装、启动和备份命令分别见
[首次初始化](../development/initialization.md)、[本机正式启动器](../deployment/local-launcher.md)和
[本机备份恢复](../deployment/local-backup-restore.md)。

## 2. 正常业务路径

1. 使用初始化命令创建的管理员账号登录；系统把活动 membership 写入服务端 session。
2. 在“客户”中新建客户。
3. 在“物料与基础资料”中依次建立单位、分类和物料；物料明确选择是否需要采购。
4. 新建项目并启用。项目编号在 tenant 内唯一，状态只能通过命名动作改变。
5. 为活动项目上传 `.xlsx` 或 `.xlsm` BOM，填写来源表头映射。
6. 在 BOM 详情逐行查看中文校验结果；无件号或疑似重复行必须明确人工处理。
7. 发布无错误的 BOM；已发布版本不可原地覆盖，新版本会保留历史。
8. 从已发布 BOM 创建投产，填写正整数台数、投产单位和接单部门，然后发布需求快照。
9. 从已发布投产生成生产请购草稿。页面带一次性幂等键，重复点击不会产生第二份有效请购。
10. 提交请购，系统按 tenant 时区分配正式编号，并在项目、投产和请购详情中保留来源关系。

## 3. 页面与安全边界

- 未登录访问业务页会转到登录页；登录成功、失败和退出均追加审计证据。
- 每次请求重新核对用户、tenant 和 membership 是否活动，停用后旧 session 立即失效。
- 所有修改使用 POST 和 CSRF 保护；列表与详情使用同一权限范围，不能靠猜测 UUID 绕过。
- 附件下载先验证关联 BOM 和项目权限，再通过附件服务读取随机内部存储键。
- 页面只做输入格式、消息和导航；权限、状态、事务、编号和审计继续由应用服务负责。
- 当前是本机单用户交付形态，不监听局域网地址，也没有云端租户选择、注册或商业授权页面。

## 4. 当前验收证据

`tests/integration/web/test_local_workbench.py` 使用 Django HTTP Client 覆盖：

- 匿名跳转、CSRF 拒绝、登录审计、成员停用；
- 从主数据到已提交请购的完整页面正常路径；
- RELATED 范围列表过滤和直接详情 UUID 猜测返回不存在；
- BOM 来源附件的授权下载。

此外，正式 `launch_local` 已在隔离 SQLite 数据目录启动，并使用真实浏览器检查登录页、工作台、
导航和表单页面；浏览器控制台没有错误或警告。P2-05 将继续验证完整业务链备份、空目录恢复和
升级演练。
