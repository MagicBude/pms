# Phase 3A 第二批：询价、采购价格核算与供应商确定

状态：已接受，待实现

## 1. 范围

本批交付 `PUR-002` 和采购侧 `MDM-005`：为已提交生产请购明细录入多个供应商报价；展示税率、
含税口径、有效期、交期和按申请数量计算的金额；撤销错误报价；从有效报价中确定供应商并保留
重选版本；按币种汇总已确定金额和未确定行数。

不实现自动最低价中标、汇率、询价邮件/附件、审批、采购订单、付款和整机销售报价。

## 2. 字段和状态

报价状态为 `ACTIVE → WITHDRAWN`，不可恢复。同一请购行零或一个当前决策，重选产生下一版本。

| 字段 | 规则 |
| --- | --- |
| 供应商 | 当前租户供应商；决策冻结代码和名称 |
| 报价日期/有效期 | 报价日必填且不得晚于有效期；有效期可空 |
| 币种 | CNY/USD/EUR/JPY/GBP |
| 原始单价 | 大于 0，6 位小数 |
| 税率 | 0 至 100，例如 13 表示 13% |
| 含税标志 | 明确原始单价是否含税 |
| 最小订购量 | 可空或大于 0；选择时申请数量必须满足 |
| 交期天数 | 可空或非负整数 |
| 来源 | 供应商报价、历史采购、ERP、人工依据及可选来源编号 |
| 备注 | 最多 500 字，不作为物料身份键 |

## 3. 采购价格核算

申请数量 `Q`、原始单价 `P`、税率百分数 `R`：

- 含税报价：`含税金额 = round(Q×P, 2)`，`未税金额 = round(Q×P/(1+R/100), 2)`；
- 未税报价：`未税金额 = round(Q×P, 2)`，`含税金额 = round(Q×P×(1+R/100), 2)`；
- `税额 = 含税金额 - 未税金额`。

不同币种分组展示；最低金额不自动等于最终供应商。

## 4. 权限和审计

- 管理员、项目负责人、生产/采购申请人员按项目范围查看；管理员和生产/采购申请人员维护。
- BOM 工程和审计角色首版不查看供应商商业报价。
- 创建、撤销和确定均审计；摘要不记录银行资料或自由文本备注。
