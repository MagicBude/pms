## 2026-08-24：修复 F-011 Linux 连续重启端口误判

### 现象与定位

- 公开 API 将失败定位到恢复目录的第二次 `launch_local`。该步骤刚停止第一个处理过 ready

### 修复

- 端口预检在 bind 前设置 `SO_REUSEADDR`，只复用刚关闭的本地监听地址，不绕过仍在监听的真实
  占用；既有“活动 listener 必须拒绝”测试继续保留。
