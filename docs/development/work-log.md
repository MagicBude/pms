- 更新架构和部署导航，使后续接手者能区分“提议”与“已接受”决策。

### 判断

- 推荐 Python 3.14、Django 5.2 LTS、服务端模板和 HTMX，以一套模块化单体支持本机、内网和云端。
- SQLite 仅用于本机单用户；进入内网多人阶段即切换 PostgreSQL 18，禁止共享数据库文件。
- 采用共享数据库、共享 Schema 和显式 `tenant_id`，P0 不依赖 PostgreSQL RLS，但所有租户查询和约束都必须显式隔离。
- 附件二进制与业务元数据分离，通过存储适配器从本地文件系统演进到对象存储。
- 上述内容均为提议，用户接受前不得据此锁定工程实现。
