# ADR-0005 数据可移植性与旧系统只读提取

状态：已接受
日期：2026-08-24

## 背景

旧 PMS 的真实业务数据分散在 `.xls`、`.xlsx`、`.xlsm`、`.xlsb`、PDF、图纸和目录结构中。
其中核心数据库使用 `.xlsb`，包含客户、供应商、项目物料、订单、入库、付款、发票和员工等
真实敏感数据。仅靠人工重新录入既不可行，也无法证明迁移完整性。

PMS 还需要支持换电脑、内网升级和未来租户迁移。这些场景虽然都可称为“导入导出”，但目的、
完整性要求和安全边界不同，不能用一个任意数据库转储命令混在一起。

## 决策

### 1. 分成三条独立通道

1. **整机迁移和灾难恢复**使用正式备份/恢复包，保持 SQLite、附件和版本清单的一致时间点。
2. **旧系统迁移**使用“只读原始提取 → 版本化映射包 → 正式应用用例 → 对账签收”流水线。
3. **业务交换与租户导出**使用按模块定义的稳定格式，只导出当前 tenant 获准的数据和附件。

原始提取包不是新系统公开导入格式；数据库备份也不是供用户编辑的业务交换格式。

### 2. 旧工作簿只读解析

- 使用 `python-calamine` 读取 `.xls`、`.xlsx`、`.xlsm` 和 `.xlsb`，不启动 Excel、不执行 VBA、
  不计算公式、不保存旧文件。
- 数据源必须在代码白名单中声明固定相对路径、工作表和精确表头；源结构漂移时停止，不猜列。
- 每个源文件记录 SHA-256、字节数、工作表、表头和有效记录数。
- 原始行保存来源行号；文本、布尔、十进制数、日期、日期时间和时间使用显式类型包装。
- JSON 中的数值使用字符串表达，禁止二进制浮点数直接成为金额或数量契约。
- 输出目录必须尚不存在；全部数据集成功后才原子发布，禁止覆盖既有迁移证据。

### 3. 敏感数据边界

- 客户税号和账户、供应商账户、订单金额、付款、发票、员工身份证和银行卡等标记为高敏感。
- 高敏感数据只有收到显式命令选项后才提取；普通日志只显示数据集数和记录数，不显示业务值。
- 真实原始包、映射中间包、对账报告和附件只放 `.internal/` 或仓库外受控目录，禁止进入 Git。
- 测试只使用完全虚构工作簿；自动化测试不得依赖 `.internal/legacy-pms/`。

### 4. 正式导入

原始行不能直接写 ORM。每个模块必须先定义版本化映射 schema、稳定业务键、空值和日期解释、
Decimal 精度、去重规则、状态映射和验收合计，再通过正式应用服务导入。重复导入时，一致对象
可以复用；同一业务键内容不同必须停止并形成冲突报告，不能静默覆盖。

### 5. 新系统导出

后续模块导出必须：

- 从可信服务端 tenant 上下文取数并执行对象权限；
- 包含 schema version、应用版本、生成时间、tenant、记录数和内容摘要；
- 对金额、数量、日期、状态和附件使用稳定契约；
- 支持重新导入时的幂等键和结构化错误；
- 对导出动作本身进行审计，不把其他 tenant 或服务端内部路径带入包。

## 备选方案

### 通过 Excel COM 自动化读取

可以覆盖本机 Excel 格式，但依赖已安装 Office、Windows 会话和 COM 安全设置，容易意外触发链接、
加载项或宏，也不适合 CI 和服务器，因此不采用。

### 先把所有 `.xlsb` 手工另存为 `.xlsx`

短期简单，但无法证明批量转换没有漏行、类型变化或公式缓存差异，还要求人工重复操作，因此不
作为正式迁移链。

### 直接读取旧表并写新数据库

开发速度看似更快，但会绕过业务规则、权限、审计、幂等和冲突报告，失败后难以恢复，因此禁止。

### 只复制 SQLite 文件换电脑

会遗漏附件、版本和完整性检查；复制过程中若服务仍在写入还可能得到不一致快照，因此换机必须
使用正式备份/恢复包。

## 后果

### 正面

- 旧核心 `.xlsb` 可以在不运行宏的前提下批量提取，不需要逐条手工录入。
- 原始证据、业务映射和正式数据库写入相互隔离，错误解释不会直接污染新库。
- 换电脑、旧系统迁移和未来租户交换各自有可验证的格式与恢复语义。

### 代价

- 每个业务模块都要建立字段映射、冲突规则和对账，不能一次“全表复制”宣称完成。
- `python-calamine` 是带 Rust 二进制轮子的新增迁移依赖，需要锁版本、CI 导入和安全审计。
- 原始包包含真实敏感数据，需要受控复制、备份、清理和访问管理。

## 复审条件

- 旧工作簿出现密码保护、损坏文件或 Calamine 无法解释的专有对象。
- 数据规模需要流式分片、断点续传或后台任务。
- 法规或合同要求对迁移包加密、签名、不可变留存或限定数据驻留位置。
- 商业云端需要客户自助导入或跨租户迁移。
