## ADR 命名

```text
ADR-0001-short-title.md
ADR-0002-short-title.md
```

每份 ADR 至少包含：状态、背景、决策、备选方案、后果和复审条件。

状态含义：

- `提议`：已形成可评审方案，尚不能作为不可变实施前提；
- `已接受`：已经评审，可进入实现；
- `已取代`：由更新的 ADR 替代，仍保留历史；
- `已废弃`：决定不再适用，但仍保留原因和后果。
