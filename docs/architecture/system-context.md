# 系统上下文

状态：草案

## 1. 目的

本文件定义 PMS 与使用者、旧系统、数据库、附件存储和未来外部服务的边界。它描述“谁与系统交互”，不展开模块内部实现。

## 2. 上下文图

```text
                          ┌─────────────────────┐
                          │ 许可证/订阅服务      │
                          │ 未来云端能力         │
                          └──────────┬──────────┘
                                     │ 签名许可或 entitlement
                                     │
┌──────────────┐  HTTPS/localhost  ┌─▼────────────────────────┐
│ 业务使用者    ├──────────────────►│ PMS 应用服务             │
│ 浏览器        │◄──────────────────┤ 页面、用例、权限、事务    │
└──────────────┘                    └─┬───────────┬───────────┘
                                     │           │
                           ORM/SQL   │           │ Storage API
                                     │           │
                            ┌────────▼───┐   ┌───▼──────────────┐
                            │ SQLite 或  │   │ 本地/服务机文件系统│
                            │ PostgreSQL │   │ 或对象存储         │
                            └────────────┘   └──────────────────┘
                                     ▲
                                     │ 只读导入、对账和迁移
                          ┌──────────┴──────────┐
                          │ 旧 Excel/VBA 系统    │
                          │ 不属于运行时依赖     │
                          └─────────────────────┘
```

## 3. 参与者

| 参与者 | 目标 | 通过什么边界进入 |
| --- | --- | --- |
| 系统管理员 | 初始化、配置、成员、备份和审计 | 受认证的浏览器页面或管理命令 |
| 项目负责人 | 管理项目生命周期 | 浏览器页面和应用服务 |
| BOM 工程人员 | 导入、校验和发布 BOM | 浏览器上传与应用服务 |
| 生产/采购申请人员 | 发布投产并提交请购 | 浏览器页面和应用服务 |
| 只读/审计人员 | 查询来源、状态和审计 | 受范围约束的浏览器页面 |
| 运维人员 | 部署、升级、备份、恢复和监控 | 管理命令和部署平台，不直接改业务表 |

## 4. 外部系统与数据源

| 外部对象 | 当前关系 | 未来关系 |
| --- | --- | --- |
| 旧 Excel/VBA PMS | 只读需求、迁移和验收基线 | 分模块停止新增，仅保留归档 |
| BOM Excel 文件 | 不可信上传输入和来源附件 | 可扩展其他结构化导入格式 |
| ERP 数据 | 当前不在 `SLICE-001` | 通过导入适配器或正式 API 集成 |
| 邮件/通知 | 当前不在范围 | 通过通知适配器发送提醒 |
| 许可证服务 | 当前只规划接口 | 私有化验证签名许可，云端读取订阅权益 |
| 对象存储 | 本机阶段不使用 | 云端保存附件二进制内容 |

## 5. 信任边界

- 浏览器、上传文件、URL 参数、表单字段和请求头全部是不可信输入。
- PMS 应用服务是唯一可以改变业务数据和状态的入口。
- 数据库和附件存储不直接暴露给浏览器或其他电脑。
- 旧工作簿、VBA、公式、外部链接和嵌入对象一律不得执行。
- 租户上下文、成员身份和权限必须在服务端建立，不能信任客户端传入的 `tenant_id` 或角色。
- 管理命令和迁移拥有更高权限，必须限制运行环境并记录操作。

## 6. 部署形态不改变的边界

本机、内网和云端只替换配置与基础设施适配器：

- 浏览器始终只访问 PMS 应用服务；
- 业务用例、领域规则、权限代码和状态机保持一致；
- SQLite 与 PostgreSQL 通过同一 ORM 模型和迁移表达；
- 本地文件系统与对象存储通过统一附件接口替换；
- 本机默认租户与云端真实租户使用同一数据归属规则。

## 7. 非边界

- PMS 不直接控制 Excel 桌面应用。
- PMS 不在浏览器中直接打开或写入 SQLite。
- PMS 不把共享目录中文件是否存在当作业务状态。
- PMS 不在首版承担 ERP、财务软件、即时通信或通用流程平台职责。
