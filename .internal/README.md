# 本机内部参考区

此目录保存不属于新仓库版本控制范围的本机材料。

## legacy-pms

`legacy-pms/` 是原 Excel/VBA PMS 系统的完整快照，用途包括：

- 回顾现有业务流程和用户操作习惯；
- 提炼业务规则、字段、编号和报表定义；
- 准备数据迁移工具和测试样本；
- 作为新系统功能验收的行为基线；
- 在新系统尚未覆盖功能时进行人工对照。

## 保护要求

- `legacy-pms/` 已被 Git 忽略，不会随仓库克隆到其他设备。
- 旧系统中可能包含客户、供应商、员工、财务和凭证数据，应按敏感业务数据保护。
- Git 忽略不是备份；应另行保存加密归档和校验清单。
- 新系统不得依赖本目录才能构建、测试或启动。
- 未经明确授权，不修改、删除或批量重命名旧系统文件。
